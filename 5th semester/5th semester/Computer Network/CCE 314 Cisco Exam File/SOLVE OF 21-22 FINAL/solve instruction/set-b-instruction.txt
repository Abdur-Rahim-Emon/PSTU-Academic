Step 5: Protocol & Simulation Analysis
	Web Request Execution:
	Switch Packet Tracer to Simulation Mode.
	Set Event Filters to show: DNS, HTTP, TCP, UDP, ICMP, ARP.
	From PC-1A browser, request [http://pstu.ac.bd](http://pstu.ac.bd).
	Protocol Flow:
	ARP: Broadcasts to discover Gateway MAC address.
	DNS: Sends UDP query to IP 172.169.254.93 to resolve pstu.ac.bd.
	TCP: Executes 3-Way Handshake (SYN → SYN-ACK → ACK).
	HTTP: Sends HTTP GET request and receives 200 OK response.
	Traceroute Execution:
	In Simulation mode, run tracert 172.169.254.93 on PC-1A command prompt.
	ICMP Mechanics:
	Packets start with "TTL"=1.
	R1-ISP decrements TTL to 0, drops packet, and replies with ICMP Time Exceeded (Type 11).
	Subsequent packet has "TTL"=2, allowing it to reach the destination server and receive an ICMP Echo Reply (Type 0).
